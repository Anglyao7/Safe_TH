# 护途 · 泰国行程安全中心 (Safe_TH)

> **HuTu Thailand Travel Safety Console** · 基于 Cloudflare Workers 边缘计算构建的跨境出行安全守护平台与全景实时同行雷达。

---

## ✨ 核心特性

- 🌐 **Cloudflare Workers 边缘架构**：毫秒级全球低延迟边缘响应，高可用无服务器部署。
- 🛰️ **全景高精实时雷达**：全宽大屏卫星地图，支持同房队友相对距离计算、视野自适应与聚焦锁定。
- 📍 **高德地图开放平台 (AMap 2.0) 引擎集成**：
  - 支持高精度基站、Wi-Fi 与 GPS 融合定位。
  - 自动火星坐标系（GCJ-02）转国际标准（WGS-84）纠偏算法。
  - 门牌级逆地理编码与地名实时解析。
- 🎯 **微调校准模式**：支持在地图上任意选点或拖拽头像图钉精准校准位置（打车软件同款）。
- 🔗 **专属动态追踪链接**：生成专属实时动态追踪 URL，亲友或微信群点击即可在卫星地图上实时查看位置与相对距离。
- 🚨 **一键紧急 SOS 救援中心**：生成中泰双语求救模板，整合护照、医疗与动态追踪链接。
- 🌓 **双模外观系统**：支持极客黑曜石暗色护盾与日光清新浅色模式一键无缝切换。
- 👥 **小队房间与自定义房间号**：支持自定义数字房间号加入同伴网络，实时心跳同步。

## 🛠️ 本地运行与开发

### 1. 安装依赖
`ash
npm install
`

### 2. 启动本地开发服务
`ash
npm run dev
# 或
npx wrangler dev
`
启动后访问 http://localhost:8787。

### 3. 部署上线 (Cloudflare Workers)
`ash
npx wrangler deploy
`
